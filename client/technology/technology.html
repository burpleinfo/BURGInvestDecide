Technical Architecture

How TONi Is Built

TONi is a serverless, real-time architecture built on Firebase — chosen for its zero-infrastructure overhead, sub-second sync, and offline PWA support. The entire system is deployed as a single static web application with no backend servers to manage.

GPS data flows from the Driver App to Firebase Realtime Database and propagates instantly to Admin and Passenger portals. The Eicher Fleet API serves as a fallback GPS source for vehicles with onboard telematics.

Hosting is on Firebase Hosting with a custom domain. The build is a single HTML file per portal — maximally portable, zero framework dependency for the deployed output.

Live Tracking

GPS That Actually Works
in Indian Conditions

TONi's GPS engine is designed for real-world Indian network conditions — where signal drops, urban canyons, and data throttling are everyday realities.

Primary GPS is sourced from the driver's phone via the Chrome Geolocation API, updating every 3 seconds. When phone signal is weak or the operator's vehicles have onboard telematics, the Eicher Fleet API provides a seamless hardware-based fallback.

📡

3-Second GPS Update Rate

Position data refreshes every 3 seconds from the TONi Driver App — fast enough for live map tracking without excessive data use.

🔄

Eicher Fleet API Fallback

For fleet operators running Eicher vehicles with onboard telematics, TONi pulls GPS data directly from the Eicher API as a hardware-grade backup.

🗺️

Google Maps Integration

All map rendering, routing, and turn-by-turn navigation is powered by Google Maps API — familiar, reliable, and India-optimised.

⚠️

Route Deviation Alerts

Geofenced corridors trigger automatic alerts to the admin portal and — for school routes — to parent WhatsApp groups when a vehicle leaves its assigned path.

RideSafe Technology

How the Compliance Engine Works

RideSafe isn't just a checklist — it's an automated compliance loop that runs continuously across every vehicle in the BURG network, surfacing issues before they become problems.

📥

Document Ingestion

Fleet operators upload vehicle fitness certificates, insurance, PUC, and driver documents during onboarding. Each document is stored with its expiry date.

🔍

Continuous Monitoring

The compliance engine checks document expiry dates daily, flagging items expiring within 30, 14, and 7 days with increasing urgency.

📲

Automated Alerts

WhatsApp alerts go to fleet operators on each threshold. BURG's operations team receives a parallel notification to follow up if renewal isn't confirmed.

🚫

Trip Blocking

Vehicles with any expired critical document are automatically blocked from trip assignment in the admin portal until renewal is verified.

✅

Reinstatement

Once the renewed document is uploaded and verified by BURG's compliance team, the vehicle is automatically reinstated in the active fleet pool.
